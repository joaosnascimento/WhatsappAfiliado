# Captura gratuita de links de afiliado do Mercado Livre

Esta extensão não faz login, não coleta senha/cookies e não chama endpoints internos do Mercado Livre.

Fluxo:

1. Abra o Mercado Livre normalmente.
2. Use a Barra de Afiliados ou a Central de Afiliados para gerar o link oficial.
3. Deixe o link gerado visível na página.
4. Clique no ícone da extensão.
5. A extensão procura um link `https://meli.la/...` na página e copia o resultado.
6. Cole o link no WhatsappAfiliado para associá-lo à oferta.

## Instalação no Chrome/Edge

1. Abra a página de extensões.
2. Ative "Modo do desenvolvedor".
3. Escolha "Carregar sem compactação".
4. Selecione esta pasta.

## Segurança

A extensão é deliberadamente assistida pelo usuário. O Mercado Livre orienta que os links sejam gerados pelas ferramentas oficiais do Programa de Afiliados e disponibiliza o compartilhamento por WhatsApp. O WhatsappAfiliado só aceita o link oficial depois da validação estrutural.

A automação posterior — associação da oferta, geração da mensagem por IA, deduplicação, agendamento e publicação no WhatsApp — continua automática dentro do WhatsappAfiliado.
